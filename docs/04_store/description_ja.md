# ストア説明文（日本語）

## 短い説明（Google Play用・80文字以内）

RSSで自分だけのニュースフィードを。キーワードフィルタでノイズをカット。アカウント不要・完全ローカル動作。

---

## 長い説明文（App Store / Google Play 共通）

Filto（フィルト）は、RSSフィードをベースにした、シンプルなニュースリーダーです。

アルゴリズムに振り回されず、自分が選んだ情報源だけを読みたい。
そんな人のために作りました。

---

■ 特徴

・RSSフィードを自由に登録
  興味のあるメディアやブログを自分で選んで追加できます。

・キーワードフィルタ（ブロックキーワード / 許可キーワード）
  読みたくない話題はブロックキーワードで除外。
  例外的に表示したい記事は許可キーワードで救済できます。

・グローバル許可キーワード
  どのフィルタよりも優先して表示させたいキーワードを登録できます。

・完全ローカル動作
  アカウント登録不要。データは端末内にのみ保存されます。
  外部サーバーへの送信は一切ありません。

・ライト / ダークテーマ対応
  システム設定に連動、または手動で切り替えられます。

・日本語 / 英語 対応

---

■ こんな人におすすめ

・レコメンドアルゴリズムではなく、自分で情報源を選びたい
・アカウント登録なしで使えるシンプルなアプリを探している
