# リリースノート v1.4.0

App Store の「このバージョンの新機能」／Google Play の「最新情報」にそのまま貼り付け可能。
文字数は Google Play の上限（各言語500字）内。

主なユーザー向け変更：ホームの並び順の改善（更新頻度の低いサイトの新着が埋もれなくなる）。
この変更に伴い、保存済みの記事・既読状態・お気に入りはリセットされる（フィード・フィルタ・
グローバル許可キーワード・各種設定は維持される）。内部変更（display_orderへの移行、
同期と復元の排他制御など）は記載しない。

---

## 日本語

```
・記事の並び順を改善しました。更新頻度の低いサイトの新着記事も、今まで埋もれて表示されなかったものが上位に表示されるようになりました
・この改善に伴い、保存されている記事・既読状態・お気に入りは一度リセットされます（フィード・フィルタ・設定はそのまま引き継がれます）
```

## English

```
• Improved article ordering on the home screen — new articles from less-frequently-updated sites, which used to get buried and rarely shown, now surface near the top
```
