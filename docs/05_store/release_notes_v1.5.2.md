# リリースノート v1.5.2

App Storeの「このバージョンの最新情報」／Google Playの「最新情報」に貼り付け可能。
両OSで同じ内容を使用する。Google Playの各言語500文字以内。

## 日本語

```
・記事が多い場合もホーム画面を軽快に表示できるよう、一覧と検索の読み込み処理を改善しました
・更新完了時に、追加された記事数や更新結果を画面上に表示するようにしました
・起動時に表示されるFiltoロゴを、より鮮明に見えるよう調整しました
・内部処理の安定性を改善しました
```

## English

```
• Improved home and search loading performance, especially when many articles are saved
• Added an on-screen result message after manually refreshing feeds
• Improved the clarity of the Filto logo shown at launch
• Improved internal stability
```
