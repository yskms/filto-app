## 詳しい説明（App Store / Google Play 共通）

見たくない話題は、見ない。

Filto（フィルト）は、アルゴリズムに「何を読むか」を決めてもらうのではなく、自分で読むものを決めるためのRSSリーダーです。

好きな情報源を集め、見たくない話題はキーワードで非表示に。読みながら、いらない記事やサイトも消して、自分に合ったフィードを少しずつ作っていけます。

■ 見たくない話題をキーワードで非表示

SNSで特定の言葉をミュートするように、RSSフィードの記事もキーワードで非表示にできます。

興味のない人物名、番組名、企業名、商品名などを登録すると、その言葉を含む記事をフィードから非表示にできます。

■ 見たい話題は残せる

ブロックしたい言葉があっても、例外として表示したいキーワードを設定できます。

たとえば「スポーツ」は非表示にしつつ「F1」だけは読む。
「政治」は避けつつ「テック政策」は読む。

情報の取捨選択を、自分の好みに合わせて細かく決められます。

■ 読みながら、自分のフィードを育てる

キーワードでルールを作るだけでなく、読みながら「これはいらない」と思った記事も、その場で非表示にできます。

記事はスワイプ、サイトごと不要なら長押しで非表示。間違えてもいつでも元に戻せます。

最初から完璧なフィードを作る必要はありません。読んで、消して、また読んで。自分に合ったフィードにしていけます。

■ 好きな情報源だけをまとめる

表示されるのは、あなたが登録したRSSフィードの記事だけです。

ニュース、ブログ、技術メディア、趣味のサイトなど、読みたい情報源をひとつのフィードにまとめられます。

■ 最初から完璧に設定しなくていい

アカウント登録は不要です。初回起動でおすすめのフィードが自動で入るので、すぐに読み始められます。

とりあえず読んで、いらないものを消していくうちに、自分にとってノイズの少ないフィードになっていきます。設定はあとから、使いながら整えれば大丈夫です。

■ 広告はありますが、行動は追跡しません

無料版では広告を表示していますが、興味関心に基づくパーソナライズ広告は使いません。閲覧履歴を他のアプリやサイトをまたいで追跡することもありません。

広告を完全に非表示にしたい場合は、Pro版へのアップグレードもご用意しています。

【主な機能】

・見たくない話題をキーワードで非表示
・許可キーワードによる例外設定
・記事・サイトをスワイプや長押しで非表示（元に戻せる）
・好きなRSS / Atomフィードをまとめて購読
・フィードをホームからミュート（削除せず非表示）
・優先表示したいキーワードの設定
・ホームでタイトル・本文から記事を絞り込み検索
・お気に入り保存
・「よく読む」バッジと既読数での並び替え
・表示レイアウトの切り替え
・起動時の自動更新 / 記事の保持期間設定
・ライト / ダークテーマ
・日本語 / 英語対応

読みながら、自分のフィードを育てる。
あなたのフィードは、あなたのルールで。

### v1.5.0 iOS審査の自動リジェクト（2026-09-01）と対処

自動チェックで2件指摘され、審査自体が開始されなかった。

1. **EULAリンクが説明文に無い** — 自動更新サブスクを提供する場合、利用規約（EULA）への機能するリンクをストアのメタデータに含める必要がある。Apple標準EULAを使うなら説明文にURLを書く。
2. **年齢レーティングの「広告」が「いいえ」のまま** — AdMobのバナーを載せているので「はい」にする。

あわせて、ガイドライン3.1.2は同じ情報を**アプリ本体にも**求めるため、v1.5.1でPro画面（`app/pro.tsx`）にサブスクの条件・EULA・プライバシーポリシーへのリンクを追加した。URLは `filto/constants/legalUrls.ts` に集約。
