## デモ動画/GIF の作り方（Pixel 9a）

### 1. 録画台本（15〜20秒）
1. Filto のホーム（フィルタ前）を2〜3秒見せる（消したい話題の記事が並んだ状態）
2. フィルタ画面へ → ブロックキーワードを1語入力して追加
3. ホームに戻る → その話題の記事が一覧から消える瞬間を見せる

### 2. 画面録画
- Pixel: クイック設定パネルの **「スクリーンレコード」** で録画 → mp4 が端末に保存される。
- mp4 を Mac に転送（USB / Google ドライブ / AirDrop代替アプリ など）。

### 3. X に載せる形式
- **X は GIF より mp4 動画が高画質**（GIFは15MB上限で粗くなりがち）。基本は **mp4 のまま添付が最適**。
- どうしても GIF にしたい場合のみ、下記で変換。

### 4. ffmpeg 変換コマンド（GIF が必要なとき）
```bash
# 初回のみ ffmpeg を導入
brew install ffmpeg

# 長さを詰める（開始2秒目から15秒だけ切り出し）
ffmpeg -i input.mp4 -ss 00:00:02 -t 15 -c copy trimmed.mp4

# 高画質・軽量 GIF（パレット法）
ffmpeg -i trimmed.mp4 -vf "fps=15,scale=540:-1:flags=lanczos,palettegen" palette.png
ffmpeg -i trimmed.mp4 -i palette.png -filter_complex "fps=15,scale=540:-1:flags=lanczos[x];[x][1:v]paletteuse" filto_demo.gif
```

> mp4 を Mac のどこかに置いてパスを教えてくれれば、トリミング／GIF化／容量最適化はこちらでやります。
