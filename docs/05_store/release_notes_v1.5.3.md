# リリースノート v1.5.3

App Storeの「このバージョンの最新情報」／Google Playの「最新情報」に貼り付け可能。
両OSで同じ内容を使用する。Google Playの各言語500文字以内。

## 日本語

```
・初回起動時の案内画面を刷新し、アプリの主な機能をスクリーンショット付きで紹介するようにしました
・バックグラウンドでの記事更新中はスピナーを表示し、完了時に結果をトースト通知でお知らせするようにしました
・手動更新時のスクロール位置の挙動を改善しました
・Pro画面で、文字サイズ設定によっては価格が見切れることがある不具合を修正しました
・内部処理の安定性を改善しました
```

## English

```
• Redesigned the first-launch guide with screenshots introducing the app's main features
• Added a spinner during background article updates and a toast notification when they finish
• Improved scroll position behavior during manual refresh
• Fixed an issue where the price on the Pro screen could be clipped depending on text size settings
• Improved internal stability
```
