# リリースノート v1.3.3

App Store の「このバージョンの新機能」／Google Play の「最新情報」にそのまま貼り付け可能。
文字数は Google Play の上限（各言語500字）内。

主なユーザー向け変更：ホームの絞り込み検索、サイト非表示の提案、スワイプの自動クローズ、
起動まわりの安定性向上。内部変更（DB初期化の堅牢化・空フィルタ防御など）は記載しない。

---

## 日本語

```
・ホームでタイトル・本文から記事を絞り込める検索を追加しました
・同じサイトの記事を続けて非表示にすると、サイトごと非表示にするか提案が出るようになりました
・一覧をスクロールすると、開いたままのスワイプ操作が自動で閉じるようになりました
・起動まわりの安定性を高め、その他の細かな不具合を修正しました
```

---

## English

```
• Added search to filter the article list by title or text
• When you keep hiding articles from the same site, Filto now offers to hide the whole site
• Open swipe actions now close automatically when you scroll the list
• Improved startup stability and fixed other minor issues
```
