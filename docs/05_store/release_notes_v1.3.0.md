# リリースノート v1.3.0

App Store の「このバージョンの新機能」／Google Play の「最新情報」にそのまま貼り付け可能。
文字数は Google Play の上限（各言語500字）内。

主なユーザー向け変更：整理機能の追加（記事・フィード・サイトをスワイプや長押しで簡単に非表示にでき、
あとから元に戻せる）、お気に入りを左スワイプに割り当て、フィード管理に「よく読む」バッジと既読数での
並び替えを追加、初回起動をシンプルに刷新、通信量の削減とアプリを開いた時の一覧更新の改善。
内部変更（条件付きGETの実装詳細・レンダリング最適化など）は記載しない。

---

## 日本語

```
・記事やサイトを、スワイプや長押しで簡単に非表示にできるようになりました（あとから元に戻せます）
・お気に入りは、記事を左にスワイプで登録できるようになりました
・フィード管理に「よく読む」バッジと、既読数での並び替えを追加しました
・初回起動をシンプルにしました
・通信量を削減し、アプリを開いた時の一覧更新を改善しました
・その他の細かな改善と不具合修正
```
