# リリースノート v1.2.0

App Store の「このバージョンの新機能」／Google Play の「最新情報」にそのまま貼り付け可能。
文字数は Google Play の上限（各言語500字）内。

主なユーザー向け変更：フィード取得の並列化による更新の高速化、一部の海外フィードで記事の
日時・並び順がずれる問題（英国夏時間 BST など）の修正、初期フィード構成の見直し。
内部変更（タイムゾーン略称パーサ・取得処理の並列化の実装詳細）は記載しない。
