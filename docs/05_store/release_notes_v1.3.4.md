# リリースノート v1.3.4

App Store の「このバージョンの新機能」／Google Play の「最新情報」にそのまま貼り付け可能。
文字数は Google Play の上限（各言語500字）内。

主なユーザー向け変更：フィード追加時のURL自動検出。内部変更（既知パスプローブの並列化、
パーサ関連の整理など）は記載しない。

---

## 日本語

```
・フィード追加でサイトのトップページURLを貼ると、RSSフィードを自動で見つけて登録できるようになりました
・複数のフィードが見つかった場合は選択できます
```

---

## English

```
• When adding a feed, pasting a site's homepage URL now auto-detects its RSS feed
• If multiple feeds are found, you can choose which one to add
```
